# AGENTS.md — titans-modern-ui (Titansoft internal)

> Read this file FIRST before writing any UI code in this repo or in a consumer project.
> Source of truth order: `titan.config.ts` → `registry.json` → `src/lib/fonts.ts` / `src/lib/themes.ts` → component files.

## 1. What this repo is

Internal **Arabic-first** UI library for **Titansoft** (Cairo, Egypt). Stack: **Next.js App Router + React 18 + shadcn/new-york + Tailwind + Radix + next-themes + lucide-react**.
Distribution model = **copy-paste (shadcn)**, NOT an npm package. Every component ships as files + a `registry/<name>.json` envelope with `usage` + `prompt`.

## 2. Mandatory rules (non-negotiable)

1. **RTL by default**: `<html lang="ar" dir="rtl">`. Never hard-code `dir="ltr"` on Arabic content. Latin-only fields (email, URL, code) get `dir="ltr"`.
2. **Logical properties only**: use `start/end`, `ps/pe`, `ms/me`, `text-start`, `gap`. BANNED: `ml-*`, `mr-*`, `left-*`, `right-*`, `text-left`, `text-right`, `space-x-*`.
3. **Directional icons**: arrows/chevrons that imply motion get `flip-rtl` class. Non-directional icons (search, plus) do NOT.
4. **Fonts**: default `font-cairo`. Alternatives from `src/lib/fonts.ts` only (`font-tajawal`, `font-plex`, `font-alexandria`, `font-almarai`, `font-kufi`). Load via `next/font/google` with `subsets: ["arabic", "latin"]`.
5. **Themes**: switch via `useTitan().setThemeId()` (`titans|oasis|sand|midnight|plum`) + `next-themes` for light/dark. Never invent new color tokens — override `--primary/--accent` in `globals.css` `.theme-*` only.
6. **shadcn contract**: every component accepts `className` merged through `cn()`. Variants via `cva`. Server Component by default; add `"use client"` only for Radix interactive primitives.
7. **Numbers**: KPIs/money use `tnum` class. Arabic-Indic digits (١٢٬٤٥٠) for Arabic prose, Latin digits for codes/phones.

## 3. How to consume (paste into a project)

```
1. Read registry.json → pick items.
2. Read registry/<name>.json → copy each files[].path to the SAME path in target.
3. Always copy src/lib/utils.ts (cn) + required Radix deps from dependencies[].
4. Wrap app in <TitanProvider defaultDirection="rtl"> + set <html lang="ar" dir="rtl">.
```

## 4. How to add a new component

1. Create `src/components/ui/<name>.tsx` (or `src/components/titans/<name>.tsx` for composed blocks).
2. Add preview to `src/components/docs/demos.tsx` (`DemoPreview` switch).
3. Add entry to `registry.json` (name kebab-case, titleAr/En, descriptionAr, category `ui|titans`, dependencies[], files[], usage, prompt).
4. Run `npm run registry:build && npm run registry:validate && npm run typecheck`.
5. Add nav link in `src/lib/nav.ts` if it deserves a docs page (page auto-renders at `/components/<name>`).

## 5. Prompts library

- `prompts/use-component.md` — build a screen from existing components.
- `prompts/new-component.md` — scaffold a new component to this standard.
- `prompts/rtl-review.md` — audit a file for RTL/Arabic issues.
- `prompts/screen-builder.md` — generate a full auth/dashboard/table page.
- Docs render: `/prompts`.

## 6. Validation checklist (run before PR)

- [ ] `npm run registry:validate` passes, `npm run typecheck` passes, `npm run build` passes.
- [ ] No banned utilities (`ml-`, `mr-`, `text-left`, `space-x-`) — grep `src/components`. Exception: `text-left` + `dir="ltr"` is allowed ONLY on Latin-only runs (email/URL/code blocks).
- [ ] Renders correctly in both `rtl` + `ltr` (DirectionToggle) and light + dark.
- [ ] Arabic copy reviewed (Egyptian-friendly MSA, جنيه مصري `ج.م` for money).

| Path | Purpose |
|---|---|

| `src/lib/fonts.ts`, `src/lib/themes.ts` | font + theme catalogs |
